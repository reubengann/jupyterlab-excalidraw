# jupyterlab_excalidraw

[![Github Actions Status](/workflows/Build/badge.svg)](/actions/workflows/build.yml)

A JupyterLab extension for creating and editing persistent
[Excalidraw](https://excalidraw.com/) drawings. Drawings are stored as native
`.excalidraw` files and open tabs are restored with the JupyterLab workspace.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install jupyterlab_excalidraw
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall jupyterlab_excalidraw
```
